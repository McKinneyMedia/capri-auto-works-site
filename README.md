# Capri Auto Works

Live: https://www.capriautoworks.online/

Static HTML/CSS hosted by Vercel project `capri-auto-works`, deployed from GitHub `main`.

- `index.html`: content and semantic sections
- `assets/tokens.css`: shared brand colors
- `assets/site.css`: reusable styles and responsive layouts
- `assets/`: Figma logo, optimized shop photograph and icons
- `docs/figma-workflow.md`: frame mappings, release process and current scope
- `robots.txt`, `sitemap.xml`: search crawler entry points

No build step. Preview with `python3 -m http.server 8765`.

Figma: https://www.figma.com/design/YSHGKtN5oZDft5ds96ZKYH?node-id=1-107

Follow [the update workflow](docs/figma-workflow.md). Figma edits do not automatically change production.
